About the Appliance Energy Consumption Website.

About This Website

The Appliance Energy Consumption Website is a small educational website designed to demonstrate basic web-development concepts using HTML, CSS and JavaScript.

The website focuses on household appliance energy consumption in the Australian market, with particular attention given to televisions.

The project demonstrates how multiple HTML pages can be connected through a navigation menu and styled consistently using an external CSS stylesheet.

What This Project Demonstrates

HTML

HTML is used to structure the content and create the three pages of the website.

CSS

CSS is used to create a consistent visual design, navigation menu, cards, buttons and responsive layout.

JavaScript

JavaScript provides interactivity through the FAQ accordion and automatically displays the current year in the footer.

GitHub

Git and GitHub can be used to track changes to the project through regular and meaningful commits.
